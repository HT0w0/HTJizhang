# HT记账 — 产品设计文档

> 这份文档是写给使用者看的。它说明 HT记账 到底是一个什么样的软件、有哪些功能、每个界面长什么样。
> 最后的「待定事项」列出了还没决定的问题。

**文档版本**：v1.0（2026-10-03）
**当前状态**：设计已确认，尚未开始编码

---

## 一、一句话介绍

**HT记账**是一个装在自己电脑上的记账软件，用来记录每天的每一笔收入和支出，并且用图表告诉你钱花到哪儿去了。

**它和手机记账 App 的区别**：数据只存在你自己的电脑里，不上传、不联网、不需要注册账号，没有人能看到你的账目。

---

## 二、这个软件是给谁用的

| | |
|---|---|
| 使用者 | 你一个人 |
| 使用设备 | 一台 Windows 电脑和一台 Mac 电脑**各自独立**使用（数据不互通） |
| 记账货币 | 人民币（元） |
| 电脑水平 | 会用鼠标点软件即可，不需要懂任何技术 |

> ⚠️ **重要说明**：由于数据存在本地，Windows 和 Mac 上记的账是**两份独立的账**，不会自动同步。如果以后需要两边看到同一份账，需要另外设计方案（比如加云同步），这是本期不做的。

## 三、能做什么（功能清单）

### 3.1 记一笔账

这是最常用的功能，也是打开软件后的第一个页面。

可以记录一笔**支出**或一笔**收入**，每笔账包含：

| 内容 | 是否必填 | 说明 |
|---|---|---|
| 金额 | ✅ 必填 | 单位「元」，可以精确到分，如 `12.34` |
| 分类 | ✅ 必填 | 必须选到**二级小类**，比如「餐饮 → 早餐」 |
| 日期 | ✅ 必填 | 默认今天，可以改成过去的日期（补记上周的账） |
| 备注 | 选填 | 一段文字，如「和同事聚餐」 |
| 支付方式 | 选填 | 微信 / 支付宝 / 银行卡 / 现金 / 其他，默认「其他」 |

**设计要点**：记完一笔后表单自动清空，可以接着记下一笔，连续记账不用反复点鼠标。整个流程目标是在 **5 秒内记完一笔**。

### 3.2 分类管理

软件自带一套做好的分类（见第五节），**开箱即用**。同时你可以自由修改：

- ➕ **新增**一级大类或二级小类
- ✏️ **改名**（比如把「餐饮」改成「吃饭」）
- 🗑️ **删除**
- ↕️ **调整顺序**（把常用的类别排到前面）

**关于删除的安全设计**：如果某个分类下已经记过账，软件**不会直接删掉它**，而是提示你「改为归档」。归档后：

- 记账时不再看到它（列表保持清爽）
- 但**历史账单照常显示**，不会变成「未知分类」

这样设计是因为：账一旦记了，就不应该因为改了分类而错乱。

### 3.3 账单查看

- 按**月份**查看，用日期分组，每天显示当天花了多少、收了多少
- 筛选：只看支出 / 只看收入 / 全部
- 搜索：输入文字搜索备注内容（比如搜「聚餐」找出所有聚餐花销）
- **点击任意一笔账可以修改或删除**

### 3.4 统计图表

这是记账软件的价值所在——把流水变成看得懂的结论。

| 内容 | 呈现形式 |
|---|---|
| 本月支出总额 | 大号数字卡片 |
| 本月收入总额 | 大号数字卡片 |
| 本月结余（收入 − 支出） | 大号数字卡片，正数绿色、负数红色 |
| 钱花在哪些大类上 | **饼图**，按一级大类显示占比 |
| 各类别具体花了多少 | **排行榜**，按金额从高到低排列，显示金额和百分比 |
| 每个大类内部花在小类上的分布 | 点击排行榜里的某个大类，**下钻**看它内部的小类占比 |
| 最近一年每月花销走势 | **柱状图**，最近 12 个月的趋势对比 |

### 3.5 数据备份与导出

- **导出备份文件**：把全部数据存成一个文件，你可以拷到 U 盘或网盘保存
- **导出 CSV**：一种表格格式，可以用 Excel 打开查看
- **「打开数据文件夹」按钮**：一键跳到数据所在位置，方便你手动复制备份

**数据存在哪里**：

| 系统 | 位置 |
|---|---|
| Windows | `C:\Users\你的用户名\AppData\Roaming\HTJizhang\` |
| macOS | `~/Library/Application Support/HTJizhang/` |

这个位置是操作系统的标准数据目录，**卸载软件、升级版本都不会丢数据**。

## 六、软件不会做的事（明确的范围边界）

写清楚「不做什么」和「做什么」同样重要，避免你对软件产生错误预期：

| 不做 | 原因 |
|---|---|
| ❌ 不联网、不上传数据 | 这是刻意的设计，你的账目只属于你自己 |
| ❌ 不需要注册账号 | 没有服务器，也就没有账号 |
| ❌ 不做手机 App | 本期只做电脑版 |
| ❌ 不做两台电脑之间的同步 | 需要云服务，属于另一个量级的工程 |
| ❌ 不自动导入支付宝/微信账单 | 需要对接第三方接口，且涉及隐私授权 |
| ❌ 不做多人共享账本 | 单人使用场景 |
| ❌ 不做预算提醒 | 你选择的第一版范围里不包含，以后可以加 |
| ❌ 不做自动更新 | 单机软件，更新手动下载安装包即可 |

## 七、怎么把软件装到电脑上

### Windows

1. 拿到 `HT记账-1.0.0-setup.exe`
2. 双击运行
3. **会弹出「Windows 已保护你的电脑」蓝色提示** —— 这是正常现象，因为软件没有购买微软的数字签名证书（个人自用软件不值得花钱买）
4. 点「**更多信息**」→ 点「**仍要运行**」
5. 按提示完成安装，桌面上会出现「HT记账」图标

### macOS

1. 拿到 `HT记账-1.0.0.dmg`
2. 双击打开，把「HT记账」拖进「应用程序」文件夹
3. **第一次打开时会提示「无法验证开发者」或「已损坏」** —— 同样是正常现象，原因同上（没买苹果开发者账号，$99/年）
4. 处理方式：**在「应用程序」里右键点「HT记账」图标 → 选「打开」→ 再点一次「打开」**
5. 如果仍然打不开，打开「终端」，粘贴这一行并回车（只需做一次）：
   ```
   xattr -dr com.apple.quarantine "/Applications/HTJizhang.app"
   ```

> 这两个提示是操作系统的安全机制，**不是软件有问题**，也不影响任何功能。详细的图文步骤会另外写在 `docs/首次安装说明.md`。

## 八、数据安全设计（为什么你的账不会丢）

这几条是软件内部的设计决策，列出来是为了让你放心：

1. **金额用「分」记录，不用小数**
   软件内部把 12.34 元记作 1234 分。这样无论加多少笔账，都**不会有 1 分钱的误差**。（用小数存储的软件，累加几千笔后常常会出现「对不上账」的情况。）

2. **日期按你的本地时间记录，不按国际标准时间**
   否则晚上 8 点之后记的账可能被算到第二天，月底、年底统计会出错。

3. **数据存在系统标准目录**
   卸载重装、软件升级都不会影响已有的账目。

4. **备份用安全的方式生成**
   备份文件不是简单复制，而是由数据库自己导出一份「完整且一致」的副本，避免备份到一半的数据。

5. **数据库结构改动会留「升级通道」**
   以后如果增加功能需要改数据结构，软件会自动升级老数据，不会让你重新记账。

| 阶段 | 内容 | 完成后你能做什么 |
|---|---|---|
