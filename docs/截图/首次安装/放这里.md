# 把「首次安装」的截图放在这个文件夹

`docs/首次安装说明.md` 里那几张是**操作系统的弹窗**，AI 截不到，只能由人在真机上拍。

拍摄方法：按 `Win + Shift + S`，框选要拍的部分，截图会进剪贴板，
然后在聊天框里按 `Ctrl + V` 粘贴（或者存成文件丢进这个文件夹）。

## 需要哪几张

| 文件名 | 拍什么 | 能不能拍 |
|---|---|---|
| `1-已保护你的电脑.png` | 双击安装包后弹出的蓝色 SmartScreen 窗口，**要能同时看到左侧的「更多信息」** | ⚠️ 不一定拍得到 |
| `2-更多信息展开后.png` | 点了「更多信息」之后，「仍要运行」按钮出现的样子 | ⚠️ 不一定拍得到 |
| `3-安装界面.png` | 安装向导的第一个界面 | ✅ 拍得到 |
| `4-mac-无法验证开发者.png` | 暂时不用拍（Mac 版还没做） | ⏳ 等 Mac 版 |

## ⚠️ 关于前两张

这两张要拍的是「Windows 拦你」的那个窗口，而**很多电脑上它根本不出现**。

2026-10-04 实测：本项目自己的 Windows 11 测试机上，双击
`HTJizhang-1.0.0-setup.exe` **从头到尾没弹过任何拦截窗口**，只出现了一条通知，
直接就装好了。所以这两张在本机补拍不了。

要补拍得换一台「会弹这个窗口」的电脑。**缺着不影响使用** ——
`docs/首次安装说明.md` 里已经用文字把那个窗口长什么样、按钮在哪写清楚了。

## 拍之前注意

**截图里不要包含个人信息** —— 用户名、公司名、完整路径、文件名里的真实姓名。
如果弹窗上有这类信息，截图时避不开的话，先拍下来再裁掉，或者用画图工具涂掉。
